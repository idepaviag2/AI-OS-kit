# Bitácora de decisiones

Registro que **solo crece**. Nunca se borra ni se reescribe: si una decisión cambia, se
agrega una entrada nueva que dice que la anterior quedó superada.

En tres meses vas a querer saber el **por qué**, no el **qué**. Ese es el único punto de
este archivo.

Cuando decidas algo que importe, dile a tu asistente: *"regístralo en la bitácora"*.

Formato:

```
## AAAA-MM-DD — Título corto de la decisión

**Qué se decidió:** una o dos líneas.

**Por qué:** el razonamiento, incluyendo lo que se descartó y por qué se descartó.

**Qué habría que ver para cambiarla:** la señal que haría revisar esto.
```
